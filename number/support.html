Number Support

Number is a single-player ice-sliding arithmetic puzzle game. If the app does not behave as expected, try the steps below first.

Basic checks

  • Restart the app.
  • Confirm that your device is running the latest available iOS version.
  • Check the in-app settings for language, sound effects, and background music.
  • If audio does not play, confirm that silent mode is off and volume is up.

Gameplay

If a move becomes unavailable, check whether a division result would be non-integer or whether the value would move outside the allowed range.
